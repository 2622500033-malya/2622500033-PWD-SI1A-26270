## Pengembangan 

-Perubahan yang dilakukan :  memisahkan CSS dari index.html ke style.css, menerapkan CSS dari Box Model, Flexbox untuk navigasi, CSS grid untuk tata letak utama, serta maedia query dengan pendekatan mobile-frist agar tampilan website responsif pada perangkat bergerak dan desktop.
-Commit dan push Github : melakukan commit dan push secara bertahap ke Github setelah setiap tahap pengembangan dan pengujian selesai.

## Pengujian 

-Perangkat bergerak : pengujian dilakukan pada viewport 768 piksel. tampilan website menyesuaikan ukuran layar, navigasi mudah digunakan, dan tidak terjadi overflow vertical.
-Desktop : pengujian dilakukan viewport 768 piksel. tatak letak utama menggunakan CSS Grid dan navigasi menggunakan Flexbox. tampilan website berjalan dengan baik.
-Galat dan perbaikan : memeriksa dan memperbaiki kesalahan tata letak jarak antara elemen, serta tampilan pada ukuran layar yang berbeda.
-Validasi CSS : memvalidasi CSS untuk memeriksa kesalahan sintaks dan memperbaiki kesalahan sintaks dan memperbaiki kesalahan yang ditemukan.
