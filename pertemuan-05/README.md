# pertemuan-05 - Pemograman Web Dasar 
 JavaScript Dasar, Dom, Event dan Validasi Sisi Klien

 Deskripsi 
 Dokumentasi oengembangan halaman web pada P5, meliputi JavaScript, DOM, Eventn Listener, Interaksi navigasi dan Validasi formulir Sisi Klien.
 Fitur dan Pengembangan 
 [JavaScript dan DOM] : menambahkan JavaScript untuk manipulasi elemen HTML melalui DOM agar halaman web dapat menampilkan perubahan secara dinamis.
 [Event Listener] : menambahkan event listener untuk merespons tindakan pengguna, seperti klik tombol dan interaksi dengan menu navigasi.
 [Navigasi Responsif] : membuat menu navigasi yang interaktif dan mudah digunakan pada perangkat mobile maupun desktop.
 [Validasi Formulir] : menambahkan validasi menggunakan JavaScript untuk memeriksa kelengkapan data sebelum formulir dikirim.
 Tambahkan entri setiap kali ada pengembangan penting pada proyek
 Pengujian 
 [Dom] :  menguji dengan membuka halaman web dan mencoba interaksi yang mengubah elemen HTML. 
  hasil : konten halaman berubah sesuai fungsi JavaScript yang dijalankan dan elemen dapat ditampilkan dengan baik.
 [Event Listener] : menguji dengan menekan tombol pada halaman web beberapa kali.
  hasil : tombol merespons klik pengguma dan menjalankan fungsi yang telah ditentukan tanpa kesalahan.
 [Navigasi Responsif] : menguji dengan menu navigasi pada tampilan mobile dan desktop.
  hasil : menu navigasi dapat digunakan pada kedua ukuran layar, tata letak  menyesuaikan ukuran layar, dan tidak terjadi overflow horizontal.
 [Validasi Formulir] : menguji dengan mengirim formulir dalam keadaan kosong dan memasukkan data yang valid, dan memasukkan data yang tidak sesuai. 
  hasil : formulir menampilkan pesan peringatan ketika data tidak sesuai den dapat di prosess ketika data memenuhi ketentuan validasi.
